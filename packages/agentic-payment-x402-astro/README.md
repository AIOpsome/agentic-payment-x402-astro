# agentic-payment-x402-astro

Astro integration and UI components for **Agentic Pay** x402 stablecoin payments.

## Features

- **Astro Integration**: Seamless setup via `astro.config.mjs`.
- **HTTP 402 Middleware**: Autonomous AI agent negotiation on protected routes.
- **Drop-in UI Components**: `<AgenticPayButton />` and `<WalletCheckout />` with Base wallet switching and live settlement states.

## Installation

```bash
npm install agentic-payment-x402-astro agentic-payment-x402-core
```
